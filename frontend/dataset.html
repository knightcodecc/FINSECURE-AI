⚠️ Model Limitations & Feature Leakage Disclosure

PaySim Simulator Generation Artifacts

In the synthetic PaySim dataset, fraudulent transactions leave predictable balance discrepancies (account_drained, balance_error_orig, orig_balance_zero). These 6 synthetic balance-artifact features account for 55.27% of the deployed model's total feature importance weight.

Synthetic Feature Weight 55.27%
Ablation Precision (No Artifacts) 98.15%
Ablation Recall (No Artifacts) 95.11%
Ablation F1-Score 96.61%

Ablation Finding: When all 6 synthetic balance-artifact features are completely removed, the model still achieves 98.15% Precision and 95.11% Recall on the 954,393-row test split using transaction type encodings and behavioral balance ratios. This demonstrates that the model retains strong, non-leaked predictive performance.
